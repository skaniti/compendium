# Security policy

## Supported versions

Only the `main` branch is supported; there are no tagged releases yet.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository:
https://github.com/skaniti/compendium/security/advisories/new

Please do not open a public issue for security problems. Expect an
acknowledgement within seven days, best effort. There is no bug bounty.

## Scope notes

- The demo stub started by `npm run demo` is a local, single-identity
  development server and is not hardened for exposure.
- The hosted personal instance is in scope; report issues with it through
  the same channel.
