## Key takeaway for the recommendation

- **60** sacrifices entire domains: no DIY, no Fashion, no Fantasy, no Education, no Politics, no Parenting, no Climate, no distinct Religion. Usable as a minimum set for generic topics but forces painful "does this book cover fit the topic or not" decisions.
- **120** closes most gaps but still merges Science / Tech and still has no Education, Politics, Paleontology, Parenting, Climate.
- **180** closes almost all remaining gaps (Climate, Politics, Paleontology, Education) but still doesn't cleanly split Pets from Wildlife and has no Parenting.
- **240** closes every gap I can identify in the interest list except crypto, language learning, and true mental health. Adds meaningful nuance (Pets vs Wildlife, Ingredients vs Prepared, Painting vs Photography, Gardening).

**Shape-vocabulary ceiling observed:** Chemistry, Painting, Beauty, and Parenting are the categories where OpenMoji's real shape vocabulary runs out. At 240 these cap at 4-5 icons and can't go higher without reaching or padding.
