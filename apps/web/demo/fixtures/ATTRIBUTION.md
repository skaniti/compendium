# Attribution

This is a curated demo compendium: a snapshot of real, publicly accessible web pages, captured for demonstration purposes. Full extracted text and full archived page assets (images, stylesheets, and other same-page resources) are included so the demo UI can render each page's saved preview offline. Sources are listed below, grouped by domain, with a licensing note where known.

arXiv papers are licensed per-paper -- check each paper's own abstract page for its specific license. YouTube entries are transcripts with no explicit redistribution license, retained under the full-content decision above. If you are a rights holder and want content removed from this dataset, please open an issue on this repository.
